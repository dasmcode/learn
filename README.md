# This is a fork of [amosblomqvist/learn](https://github.com/amosblomqvist/learn) 

## A personal learning system with the help of pi agent harness
> [!IMPORTANT]
> check out the video made by the creator 

[![video](assets/thumbnail.png)](https://www.youtube.com/watch?v=kzcI5F4tGiU)

This fork is a modification of the original repository to ***specifically*** work with pi inside of herdr

### Requirements

- [pi](https://pi.dev/) 
- [herdr](https://herdr.dev/) 
- pi extensions : pi-herdr-subagents, pi-web-access, pi-permission-system(recommended)

  Install them with : 
  ```bash
  pi install npm:pi-web-access 
  pi install npm:pi-herdr-subagents 
  pi install npm:@gotgenes/pi-permission-system 
  ```
